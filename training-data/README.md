# Очередь для планового обучения

Положите сюда `history.csv` в формате `../docs/ML.md`. Docker монтирует каталог только для чтения. Файл имеет приоритет над CSV, загруженным через интерфейс. Обучение ежедневно в 03:00 Europe/Moscow; `ML_CRON` меняет расписание. Если новых данных нет, версия не создается.

Реальные CSV исключены из Git. Демонстрационный набор находится в `src/main/resources/demo/history.csv`.
