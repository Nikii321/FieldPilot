# Зависимости

Основные прямые зависимости загружаются Gradle из Maven Central. Этот файл не заменяет лицензионные уведомления внутри поставляемых JAR.

| Компонент | Лицензия | Назначение |
|---|---|---|
| Kotlin | Apache-2.0 | Язык и стандартная библиотека |
| Spring Boot / Spring Framework | Apache-2.0 | HTTP, DI, SQL, scheduler |
| Smile 4.4.2 | GPL-3.0 | RidgeRegression |
| PostgreSQL | PostgreSQL License | Основная БД |
| H2 | MPL-2.0 / EPL-1.0 | Локальная и тестовая БД |
| Gradle | Apache-2.0 | Сборка |
| JavaCPP | Apache-2.0 | Нативный мост для численных вычислений |
| OpenBLAS | BSD-3-Clause | BLAS / LAPACK |

Приложение распространяется под GPL-3.0-or-later. Исходный код и сценарии сборки поставляются в этом репозитории. Исходники Smile: https://github.com/haifengl/smile/tree/v4.4.2.
