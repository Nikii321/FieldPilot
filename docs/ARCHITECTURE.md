# Архитектура FieldPilot

```text
Браузер (static/index.html, app.js, style.css)
                 ↓ REST / JSON
controller → service → repository → SQL (PostgreSQL / H2)
                 ↓
       algorithm + ml/training + ml/inference
                 ↑
         scheduler → service/ml
```

`domain/` — скважина, признаки, действие, сценарий; валидация допустимых значений. Домен не зависит от Spring и JDBC.

`model/request/` — входные контракты API; `model/response/` — результаты расчетов, рекомендации и снимки. `ml/model/` — обучающие строки, метрики и сохраняемый артефакт. Один класс / enum / object на файл.

`algorithm/` — независимые математические вычисления: AHP, сценарные критерии, оптимизация и экспертные правила. Не используют HTTP или базу.

`service/` — прикладные операции и согласование результатов. `WellService` транзакционно меняет скважину и мероприятия, защищает обновления версией. `AnalysisService` получает SQL-снимок в REPEATABLE_READ и одну неизменяемую версию модели для всего расчета. `DecisionService` сохраняет полные исходные данные и результаты, а не ссылки на изменяемые карточки.

`service/ml/` — восстановление модели, активная версия, очередь истории и обучение. Кандидат не заменяет модель до проверки качества. `scheduler/` вызывает этот же сервис по cron. Артефакт и активная версия сохраняются транзакционно, ссылка в памяти переключается после сохранения.

`repository/` — SQL только здесь. Таблицы: well, well_actions, model_version, training_dataset, training_run, decision_snapshot, metadata, write_lock. Payload хранится в JSON для обозримости MVP; внешние ключи, уникальность имени и версии контролируются SQL. Миграции схемы для продакшена потребуют Flyway/Liquibase.

`config/` — стартовая инициализация, параметры расписания и демонстрационные оценки. Флаг seed не дает восстановить удаленные скважины при перезапуске.

Запись карточки требует актуальный `version`; запись мероприятий — `wellVersion`. Несовпадение дает HTTP 409. На создание фонда применяется блокировка SQL-строки, чтобы предел 12 скважин не обходился параллельными запросами. Один экземпляр приложения; кластерное обучение не реализовано.

Сервис останавливает расчет при неподтвержденном качестве данных. При отсутствии допуска остается только STOP. Если ресурсы не покрывают обязательный план — HTTP 422. Лимит поиска не позволяет выдавать частичный ответ под видом точного оптимума.
